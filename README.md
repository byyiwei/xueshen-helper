# 学神助手

网课学习辅助油猴脚本，覆盖学习通、智慧树、智慧职教、中国大学MOOC、学堂在线等平台。

## 安装

- 油猴（GreasyFork / Tampermonkey）版：[xueshen-gf.user.js](https://xs.openget.cn/xueshen-gf.user.js)
- 脚本猫（ScriptCat）版：[xueshen-sc.user.js](https://xs.openget.cn/xueshen-sc.user.js)

安装教程、功能介绍与更新日志见 [docs/script-intro.md](docs/script-intro.md)，或访问官网：https://xs.openget.cn

## 本仓库范围

本仓库仅用于脚本自动更新（`@updateURL` / `@downloadURL` 指向 raw 文件）与脚本介绍，不含服务端代码。
