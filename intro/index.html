安装学神助手

安装刷课脚本，整课托管

支持油猴 (Tampermonkey) 和脚本猫 (ScriptCat) 两种管理方式，任选其一即可

🐱 方法一

脚本猫 ScriptCat（推荐国内用户）

国内访问更稳定，支持脚本同步备份
  1. 1
    安装脚本猫扩展

    打开 Chrome/Edge 浏览器，访问 脚本猫官网 或 Chrome 扩展商店，搜索 "ScriptCat" 并安装。安装后浏览器右上角会出现猫咪图标，点击即可打开脚本猫面板。

  2. 2
    添加学神助手脚本

    点击脚本猫图标 → 点击"添加脚本" → 选择"从链接安装"或直接粘贴脚本代码。

    脚本下载渠道： ⬇️ 下载脚本猫版 Greasy Fork GitHub
  3. 3
    启用脚本并刷新页面

    添加完成后，在脚本猫面板中确保学神助手处于"启用"状态。打开 超星学习通 或 智慧树 课程页面，刷新后即可看到悬浮面板。

🐵 方法二

Tampermonkey 油猴（国际通用）

全球最大脚本管理平台，脚本生态完善
  1. 1
    安装 Tampermonkey 油猴

    Chrome/Edge 用户访问 油猴官网 或直接在扩展商店搜索 "Tampermonkey" 安装。Firefox 用户搜索 "Tampermonkey" 或 "Violentmonkey" 安装。安装后浏览器右上角会出现黑色猴子图标。

  2. 2
    安装学神助手脚本

    点击以下按钮下载脚本，油猴会自动弹出安装确认框，点击"安装"即可。

    脚本下载渠道： ⬇️ 下载油猴版 Greasy Fork GitHub
  3. 3
    打开网课页面开始使用

    安装完成后，进入 超星学习通 或 智慧树 的课程页面。页面左上角会出现蓝色"学神"悬浮球，点击进入设置面板，调整倍速和答题模式后即可全自动运行。

常见问题

你可能想知道

搜题收费吗？会扣题数点数吗？

完全免费。网页搜题走题库直查，不消耗账号的题数点数，也不需要开通会员，只要登录就能用。

为什么每天只能搜 30 次？

为了保证所有用户都能稳定使用，免费搜题每人每天限 30 次，次日零点自动重置。如果你是刷课脚本用户，脚本内答题不受此限制影响。

搜不到我的题怎么办？

题库仍在持续扩充。建议：1）题干尽量粘贴完整，去掉题号等多余字符；2）换个关键词再试；3）仍搜不到可以到 QQ 频道【学神助手】（频道号 pd22434767）留言反馈，也可以安装学神助手脚本，使用 AI 答题兜底。

这个搜题和学神助手脚本是什么关系？

网页搜题是学神助手提供的免费在线服务，与刷课脚本共用同一套题库。脚本额外支持视频倍速、自动答题、AI 兜底等功能，适合整课托管；临时查几道题，用网页搜题就够了。
