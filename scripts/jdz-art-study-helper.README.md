# 景德镇艺术-学习助手

> 一个针对「景德镇艺术职业学院」在线学习平台（o-learn.cn）的浏览器用户脚本（UserScript），用于增强课程视频的观看体验，并自动记录学习进度。
>
> - **版本**：v4.1.0
> - **作者**：IPYIWEI
> - **许可**：MIT
> - **适用域名**：`*://*.o-learn.cn/*`

---

## 一、功能简介

### 1. 视频观看体验增强
- **自动播放**：页面加载即尝试自动播放；浏览器禁音策略下先静音兜底，取得用户手势后自动恢复声音；自带多次重试与 videojs 播放器兼容。
- **自定义倍速**：0.5x / 0.75x / 1x … 16x 预设，外加自定义输入框，默认 2x。
- **倍速保持**：通过接管 `playbackRate` 的读写，网页想把倍速改回原速时自动保持设定值（日志中会提示已保持设定倍速）。
- **保持播放**：重写 `video.pause()` 行为，非用户主动触发的暂停会被忽略并自动恢复；用户自己点击的暂停仍正常生效。
- **自动下一节**：视频结束后自动寻找"下一节 / 下一个 / 下一页 / 继续学习"等按钮，或在课程目录中点击下一项，找不到再尝试键盘右方向键。
- **深度视频检测**：支持 Shadow DOM 内部视频、嵌套 iframe 视频的扫描与接管。

### 2. 学习记录与日志
- **学习记录**：本地按视频地址记录首次观看时间、累计观看时长、是否完成、最后访问时间。
- **日志面板**：实时滚动显示脚本运行日志（最多保留 200 条，可一键清空）。

### 3. 浮动控制面板
页面右上角带一个可拖拽的浮动面板，包含若干标签页：
- **首页**：当前视频状态、立即播放按钮。
- **日志**：运行日志。
- **记录**：学习记录。
- **设置**：倍速调节，自动播放 / 静音 / 自动下一节开关。

## 二、安装方法

1. 给浏览器装上 Tampermonkey / Violentmonkey 等用户脚本管理器。
2. 新建脚本，把 `jdz-art-study-helper.user.js` 全文粘贴进去保存；或直接把 `.user.js` 文件拖入管理器完成安装。
3. 打开 `*.o-learn.cn` 的学习页面，右上角出现浮动面板即生效。

> 脚本头部已声明 `@updateURL` / `@downloadURL`，管理器可据此自动检测更新。

## 三、主要配置（脚本内 `CONFIG`）

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `defaultSpeed` | `2` | 默认倍速 |
| `autoPlay` | `true` | 默认开启自动播放 |
| `autoMute` | `true` | 默认静音播放（取得手势后自动恢复声音） |
| `autoNext` | `true` | 视频结束自动进入下一节 |
| `retryInterval` | `3000` | 定期扫描兜底间隔(ms) |
| `speedLockInterval` | `1000` | 倍速保持检测间隔(ms) |
| `playRetryMax` | `10` | 自动播放最大重试次数 |
| `playRetryDelay` | `1000` | 自动播放重试间隔(ms) |
| `logMax` | `200` | 日志面板最大条数 |

偏好会持久化在油猴存储键 `jdz-art-settings-v4`；学习记录存在浏览器 `localStorage` 的 `jdz-art-records`。

## 四、技术亮点

- **`playbackRate` 接管**：用 `Object.defineProperty` 重写视频元素的倍速读写，实现"网页改倍速无效"。
- **暂停逻辑调整**：重写视频暂停方法，区分用户主动暂停与网页自动暂停。
- **`MutationObserver`**：持续监听整棵 DOM 树的 `video` 节点插入，新视频自动接管。
- **SPA 路由监听**：监听 `history.pushState / replaceState` 并监听 `hashchange / popstate`，页面切换后自动重新扫描视频。

---

## 五、注意事项

- **数据安全**：脚本仅在本地处理播放与记录数据，设置与学习记录存于本地（油猴存储 / 浏览器 localStorage）。
- **跨域限制**：嵌套于第三方域名的 iframe 视频，因浏览器同源策略可能无法直接操作，脚本会尽力但未必全部接管。
- **兼容性**：脚本基于 o-learn.cn 当前页面结构编写，平台页面改版后可能需要相应更新。
